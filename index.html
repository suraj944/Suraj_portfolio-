Recurring Task Automation System

A working proof of concept for Allo Innoware that tracks recurring team tasks, collects completions from employees and escalates anything that slips, built entirely in Google Sheets with Apps Script.

  • Recurring tasks on daily to 30-day cycles; the next due date recalculates automatically the moment a task is completed
  • Employees update a single cell: a ticket ID for portal tasks, or DONE for daily tasks, validated by the script so a ticket task can't be closed with DONE
  • Live manager dashboard of every overdue and due-today task, with an acknowledgement checkbox per task
  • Daily automated emails: a same-day alert to the manager, then escalation to leadership after 24 hours without acknowledgement or 72 hours unresolved, each sent only once
  • All timings set in an SLA settings tab, every event written to an audit log, and sheet protection so employees can only edit their own input cells
  • Google Sheets
  • Apps Script
  • QUERY
  • Email automation
